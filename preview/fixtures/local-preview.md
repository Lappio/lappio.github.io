## 行宽

正文待在一条固定的行宽里。句子有长有短，用来看字号、行距和段间距是否站得住。

> 引用用来看强调的方式。它仍然是预览文字，不是摘录。

- 第一项看列表的缩进
- 第二项看行距
- 第三项看标记

行内代码 `prefers-reduced-motion` 应该和句子坐在一起。代码块单独成段：

```css
.essay {
  max-width: 66ch;
}
```

预览到这里就可以。
